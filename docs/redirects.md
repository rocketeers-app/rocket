# Redirects

List redirects for an environment.

```bash
rocket redirects --team=<team> --environment=<environment> # List Redirects
rocket redirects --create --team=<team> --environment=<environment> -F source=<source> -F destination=<destination> # Create Redirect
rocket redirects --update --team=<team> --environment=<environment> --id=<id> # Update Redirect
rocket redirects --delete --team=<team> --environment=<environment> --id=<id> # confirms; --force to skip
```
