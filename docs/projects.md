# Projects

List projects in a team.

```bash
rocket projects --team=<team>                        # List Projects
rocket projects --team=<team> --id=<id>              # Get Project
rocket projects --create --team=<team> -F name=<name> # Create Project
rocket projects --update --team=<team> --id=<id> -F name=<name> # Update Project
rocket projects --delete --team=<team> --id=<id>     # confirms; --force to skip
```
