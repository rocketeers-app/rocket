# Incidents

List incidents in a team or for a domain.

```bash
rocket incidents --team=<team>                       # List Incidents
rocket incidents --team=<team> --id=<id>             # Get Incident
rocket incidents --team=<team> --domain=<domain>     # Incidents
rocket incidents --action=acknowledge --team=<team> --id=<id> # Acknowledge
rocket incidents --action=investigate --team=<team> --id=<id> # Investigate
rocket incidents --action=monitor --team=<team> --id=<id> # Monitor
rocket incidents --action=resolve --team=<team> --id=<id> # Resolve
```
