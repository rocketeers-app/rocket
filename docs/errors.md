# Errors

List errors in a team or an environment.

```bash
rocket errors --team=<team>                          # List Errors
rocket errors --team=<team> --id=<id>                # Get Error
rocket errors --team=<team> --environment=<environment> # List Errors
rocket errors --action=ignore --team=<team> --id=<id> # Ignore
rocket errors --delete --team=<team> --id=<id>       # confirms; --force to skip
```
