# Deployments

List deployments for an environment.

```bash
rocket deployments --team=<team> --environment=<environment> # List Deployments
rocket deployments --team=<team> --environment=<environment> --id=<id> # Get Deployment
rocket deployments --create --team=<team> --environment=<environment> # confirms; --force to skip
```
