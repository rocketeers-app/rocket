# Clients

List clients in a team.

```bash
rocket clients --team=<team>                         # List Clients
rocket clients --team=<team> --id=<id>               # Get Client
rocket clients --create --team=<team> -F name=<name> # Create Client
rocket clients --update --team=<team> --id=<id> -F name=<name> # Update Client
rocket clients --delete --team=<team> --id=<id>      # confirms; --force to skip
```
