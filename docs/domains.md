# Domains

List domains in a team or on a server.

```bash
rocket domains --team=<team>                         # List Domains
rocket domains --team=<team> --id=<id>               # Get Domain
rocket domains --team=<team> --server=<server>       # List Domains
rocket domains --create --team=<team> -F name=<name> # Create Domain
rocket domains --action=sync --team=<team>           # Sync
rocket domains --action=response-time --team=<team> -F ids=<ids> # Response time
```
